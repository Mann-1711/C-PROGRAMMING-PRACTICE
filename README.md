# C Programming Practice

A repository documenting my journey of learning **C programming**, strengthening problem-solving skills, and building programs independently.

This repository contains practice exercises, beginner programs, and small projects developed while learning C.

## About This Repository

The main goal of this repository is to develop strong programming fundamentals through consistent practice.

I am focusing on understanding programming logic, writing clean code, debugging errors, and gradually progressing towards more advanced concepts.

## Topics I'm Learning

- Basic syntax and structure of C
- Variables and data types
- Input and output (`printf`, `scanf`)
- Operators and expressions
- Conditional statements (`if`, `else`, `switch`)
- Loops (`for`, `while`, `do-while`)
- Functions
- Arrays and strings
- Pointers
- Structures
- File handling

## Programs and Projects

### 1. Calculator

**File:** `calculator.c`

A basic calculator that takes two numbers and an operator from the user and performs arithmetic operations.

**Operations:**
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

**Concepts Practised:**
- Variables and data types
- `scanf()` and `printf()`
- Character input using `char`
- Conditional statements
- Arithmetic operators
- Input validation
